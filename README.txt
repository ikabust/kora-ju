# 推しスクショ A4プリンター

スクショを複数選ぶだけで、画像の縦横比を変えずにA4用紙へ自動配置して印刷できる、推し活用のミニアプリです。

## できること

- スクショを複数枚まとめて選択
- 画像の縦横比をそのまま維持
- A4サイズに自動配置
- 画像同士が重ならないように配置
- A4に入りきらない画像は2ページ目以降へ自動送付
- 画像間の隙間を変更
- A4のページ余白を変更
- 並び順を変更
  - 選択した順
  - 大きい順
  - 縦長を優先
- 印刷ボタンからそのまま印刷
- オフラインで使用可能
- 選択した画像を外部サーバーへアップロードしない

## 使い方

### 1. スクショを選ぶ

「スクショを選ぶ」から、印刷したい画像を複数選択します。

### 2. 自動配置する

「A4に自動配置」を押すと、A4用紙の中に画像が自動で並びます。

画像は縦横比を変えずに配置されます。

### 3. 好みに合わせて調整する

以下を変更できます。

- 画像間隔：画像と画像の間のすき間
- ページ余白：A4の端から画像までの余白
- 並び方：画像を配置する順番

設定を変更すると、自動的にレイアウトが更新されます。

### 4. 印刷する

「印刷する」を押して、印刷画面を開きます。

基本的には以下の設定がおすすめです。

- 用紙サイズ：A4
- 拡大縮小：100%
- 余白：アプリ側の設定を優先
- ヘッダー・フッター：オフ

プリンター側にも「用紙に合わせる」「自動拡大縮小」などの設定がある場合は、意図せずサイズが変わることがあるため注意してください。

## ファイルについて

`推しスクショ_A4プリンター.html`

このHTMLファイルだけでアプリが動作します。

インターネット接続は基本的に必要ありません。

`推しスクショ_A4プリンター.zip`

HTMLファイルをまとめたZIP版です。
保管・移動するときはこちらが便利です。

## スマホで使う場合

iPhoneの場合は、HTMLファイルを「ファイル」アプリなどに保存して、対応するブラウザで開いて使用できます。

よく使う場合は、ブラウザからホーム画面へ追加しておくとアクセスしやすくなります。

## 印刷時の注意

画面上ではA4比率で表示していますが、最終的な印刷サイズはプリンターやブラウザの印刷設定にも左右されます。

特に「用紙に合わせる」「ページに合わせる」などの自動拡大縮小が有効になっていると、意図したサイズと異なる場合があります。

推し活用のスクショを「同じくらいの大きさでたくさん印刷したい」場合は、印刷前にプレビューを確認してください。
