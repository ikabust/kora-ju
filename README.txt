# 推しスクショ A4プリンター

スクショを複数選ぶだけで、画像の縦横比を保ったままA4へ自動配置する個人用ミニアプリです。

## 現在の機能

- 画像を複数枚追加
- 画像はIndexedDBへ保存
- ブラウザを閉じても保存データを再表示
- 横長画像は初期状態で90°回転
- 縦長・正方形画像は初期状態で0°
- 回転ボタンで0° / 90°を切り替え
- 指定した「短辺」を基準に画像サイズを決定
- 初期値は短辺4.5cm
- 縦方向に上から配置し、列がいっぱいになると右の列へ移動
- A4に入りきらない場合は次ページへ
- 画像間のすき間を変更
- A4の余白を変更
- ドラッグ＆ドロップで並び順を変更
- 削除モードで個別削除
- 全部削除
- ブラウザの印刷機能からA4 PDF / 印刷
- スマホではA4全体を画面幅に合わせて縮小表示
- Service Workerによるオフライン利用と更新
- 画像を外部サーバーへアップロードしない

## 印刷時

A4・倍率100%・「用紙に合わせる」などの自動拡大縮小をオフにしてください。

## ファイル構成

- index.html：画面とアプリバージョン
- style.css：画面・A4・印刷用CSS
- script.js：画像保存・配置・回転・削除・並び替え
- sw.js：PWAのキャッシュと更新処理
- manifest.json：ホーム画面追加などのPWA設定
- icon.png：アプリアイコン

## バージョン

v1.4.7

IndexedDBのDB_VERSIONは4のままです。
これはデータ構造のバージョンであり、アプリの表示バージョンとは別物です。
