# 推しスクショ A4プリンター v1.4.9

スクショを選ぶだけで、画像の縦横比を保ったままA4へ自動配置する個人用ミニアプリです。

## v1.4.9の変更

画像の一時保存を廃止しました。

- アプリを閉じると画像は残りません
- アプリを再起動すると空の状態から始まります
- IndexedDBによる画像保存は使用しません
- 画像データをブラウザへ永続保存しません
- 4.5cm・すき間・余白の設定だけlocalStorageへ保存します

## 主な機能

- スマホで画像を長押しして、その場所の画像だけ入れ替え

- 画像を複数枚追加
- 画像の縦横比を維持
- 横長画像は初期状態で90°回転
- 回転ボタンで0° / 90°を切り替え
- 回転後の短辺を指定サイズにする
- A4へ自動配置
- 画像間のすき間を変更
- A4の余白を変更
- ドラッグ＆ドロップで並び順変更
- 個別削除・全部削除
- ブラウザの印刷機能からPDF / 印刷
- スマホではA4全体を画面幅に合わせて縮小表示
- PWA / Service Worker対応

## 印刷

A4・倍率100%・自動拡大縮小なしで印刷してください。

## ファイル構成

`script.js`と`sw.js`は役割が異なるため、統合せず分離しています。
